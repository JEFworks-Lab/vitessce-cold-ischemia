Usage

Use the mouse to pan and zoom. Hold the Control key to rotate. Hold the Shift key and hover over spots to display more information. Toggle light/dark mode with the switch at the top of the right panel. Click and drag between panels to extend/shrink their size.

Click the legend to change the color palettes. If gene is selected, move sliders to adjust gene range in legend.

On the right is the control/gene panel. In the control panel, use the drop down to select what coordinates to display and highlight/color the data by kidney compartment (default) or other attributes. In the control panel, you have the option to search for a gene to color the data. Add filters to filter the data by different attributes.

In the gene panel, filter/search for genes of interest based on upregulation or downregulation in different compartments (eg. Cortex Up- upregulated in cortex) or based on linear regression slope values (eg. Inner Medulla Slopes) using dropdowns and entries. Click a gene to display gene expression for that gene in the data panel and to view its expression in the timecourse plot panel. For searching for upregulated/downregulated genes, use the dropdown at the top to display all upregulated/downregulated genes or not. For searching for genes using slope values, use commands !nan (remove NaN ganes), nan (show only NaN genes), > (greater than), < (less than). Example entries: !nan >0; !nan, >10.

In the bottom timecourse panel, toggle the triangle in the upper right corner to display/hide the timecourse plot. Sslect/unselect kidney compartments to show on plot.

Reset camera and point size with the buttons in the control panel. Adjust point size and sample rate with the sliders in the control panel.
